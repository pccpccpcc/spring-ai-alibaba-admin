# 需求草稿：Overview 总览首页

- 草稿日期：2026-06-18
- 状态：草稿（阶段 1，待评审）
- 相关：落地页改造（`.umirc.ts` 路由），新增前端页面

---

## 1. 业务目标

让用户（尤其新人）一进入平台就能看到：① 平台有哪些功能（**功能地图**）；② 当前现状（**关键计数**）；③ 下一步做什么（**新手引导**）。解决"一进来直接到应用列表、不知道平台全貌"的问题。

---

## 2. 用户场景与痛点

**典型场景**
- **新人首次进入**：看到 `/app` 应用列表（空或少量），不知道平台还有 Prompt 工程、评测、知识库、MCP、可观测、模型服务等模块，不知道第一步做什么。
- **老用户进入**：想快速看平台现状（多少 Prompt / 应用 / 最近评测），要逐个点模块才知道。

**当前痛点**
- 无总览页，功能发现靠侧边栏逐个点（侧边栏 9+ 模块，新人 overwhelm）。
- 现状不可见（计数/最近活动分散在各模块）。
- 新人无引导（不知道先配模型、再建 Prompt、再搭应用的顺序）。

---

## 3. Overview 页面结构

### 3.1 功能地图（核心，常驻）
卡片网格，每张卡片 = 模块入口：
- Prompt 工程 / 评测·实验 / 应用·工作流 / 知识库 / MCP / 组件·插件 / 可观测 / 模型服务 / Playground
- 每卡片：模块名 + 一句话说明 + **计数**（如「12 个 Prompt」）+ 点击进入

### 3.2 关键指标（常驻）
顶部摘要：Prompt 数 / 应用数 / 评测实验数 / 知识库数（从功能地图计数抽取关键几个）。

### 3.3 新手引导卡片（空状态，条件显示）
当**关键数据全空**（无模型配置 + Prompt=0 + 应用=0）时显示，3 步引导：
1. 配置模型服务 → `/setting/modelService`
2. 创建第一个 Prompt → `/admin/prompts`
3. 搭建应用 / 工作流 → `/app`

每步：步骤号 / done 状态（✓）/ 说明 / CTA 按钮。数据有了则隐藏引导（或折叠），让位给功能地图。

---

## 4. 接口契约（数据来源 —— 待决策 D1）

Overview 需要各模块计数 + 引导状态。**数据来源两个选项**（阶段 2 确认现有接口能力，阶段 3 定）：

| 选项 | 做法 | 代价 |
|---|---|---|
| **A（已定 D1）** | 复用现有列表接口的 `totalCount`，前端并行聚合 | 零新接口；前端多请求。**后端零改，不做基线测试**（基线测试用于防后端被改坏，本需求不动后端，故不锁——用户决策） |
| B | 新增 `GET /api/overview/stats` 后端聚合，一次返回所有计数 + 引导状态 | 新接口；一次请求但加后端逻辑 |

**引导 done 状态判断**（选项 A 下，前端用现有接口判断）：
- 模型配置：Provider/Model 列表非空
- Prompt：`promptCount > 0`
- 应用：`appCount > 0`

> 落地页：`/` redirect 从 `/app` 改为 `/overview`（新增 `/overview` 路由 + Overview 页组件）。

## 5. 边界场景清单

| # | 场景 | 标注 | 预期 / 处理 |
|---|---|---|---|
| 1 | 新用户全空（无模型/Prompt/应用） | 基于设计 | 显示引导卡片（3 步全未完成）+ 功能地图（计数 0） |
| 2 | 部分完成（配了模型没建 Prompt） | 基于设计 | 引导卡片显示 ①done ②③undone；功能地图显示已有计数 |
| 3 | 数据齐全（有 Prompt/应用） | 基于设计 | 隐藏引导卡片，显示功能地图 + 计数 |
| 4 | 落地页：`localhost:8081/admin` 进入直接跳 overview | ✅ 已定（D2） | `/admin` 入口跳 overview；`/app` 保留直达；实现方式（`/admin` redirect 到新 overview 路由，或改 `/admin` 默认组件）阶段 2 定 |
| 5 | 计数加载中 vs 0 | 基于设计 | loading 态显示骨架/占位，**避免显示 0 误导**（0 是真值，加载中不是） |
| 6 | 某模块计数接口失败 | ✅ 已定（D3） | 该卡片计数显示「—」**不阻塞整页**，但提供「重试」按钮（单卡片重试）+ 页面可刷新 |
| 7 | 引导「模型配置已完成」判断 | ✅ 已定（D4） | 看 **Provider 列表非空**（更接近"配过模型服务"语义）；Prompt>0；应用>0 |
| 8 | 模块权限/禁用 | 基于现有 | 功能地图所有模块都展示（项目无模块级权限开关，本期不引入） |
| 9 | 移动端响应式 | 基于设计 | 卡片网格响应式（手机 1 列 / 平板 2 列 / 桌面 3-4 列） |
| 10 | 计数实时性 | 基于设计 | 进页面加载一次（不轮询）；用户从子模块返回 overview 时重新加载 |
